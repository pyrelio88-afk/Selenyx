# 界面整体概览
这是一款面向学术、临床研究场景的移动端「AI研究助手」应用界面，整体为浅米白的极简设计风格。
---
## 顶部导航区
1.  左上角：汉堡功能菜单按钮
2.  顶部居中：页面主标题「**AI助手**」
3.  右上角：月亮形状的暗色模式切换按钮
4.  次导航栏：
    - 左侧：小菜单按钮 + 标签「AI研究助手」
    - 右侧：红色文字标注的「**未配置**」下拉按钮，提示API密钥还未完成设置
---
## 中间功能说明区
1.  顶部有浅绿星形装饰图标，下方是大标题「**AI研究助手**」
2.  提示文字：
    > 请先在「设置」中配置 LLM API Key（BYOK）
    > 支持能力：文献综述 / 论文批评 / 想法生成 / 数据提取 / SBAR交接 · 输入 / 召唤更多指令

### 分类功能按钮
按使用场景分为4类：
| 功能分类 | 对应功能按钮 |
|---------|--------------|
| 研究类 | 📑 文献综述<br>ⓘ 研究想法 |
| 分析类 | 📑 论文批评<br>📊 数据提取<br>📊 统计咨询 |
| 写作类 | ✍️ 写作润色 |
| 临床类 | ⚕️ SBAR交接 |
---
## 底部输入区
1.  输入框占位提示：`先在「设置」配置 LLM API Key...`
2.  右侧是浅灰绿色的发送按钮，当前处于未激活不可用状态
3.  最底部隐私提示小字：`BYOK · 浏览器直连，Key 不出本机`，说明用户自定义的API密钥仅在本地设备运行，不会上传，保障数据安全。
