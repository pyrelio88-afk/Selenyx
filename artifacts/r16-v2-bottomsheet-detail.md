# 文献库空状态界面
这是文献管理工具「Selenyx」的文献库初始页面，整体为浅米白简约风格，当前还没有存入任何文献：
1.  **顶部导航栏**
    - 左上角：汉堡菜单按钮
    - 居中：页面标题「文献库」
    - 右上角：深色模式切换的月亮图标
2.  **功能操作区**
    - 顶部右侧并列两个功能按钮：白底黑字的「… 更多」按钮、绿底白字的「+ 新建」按钮
    - 通用搜索框：占位提示为`搜索标题、作者、DOI…`
    - 带漏斗图标的「筛选」按钮
    - DOI抓取区域：左侧输入框提示`粘贴 DOI 自动抓取文献信息（如 10.`，右侧对应绿底白字的「抓取元数据」按钮
3.  **空状态提示**
    页面居中显示空文档图标，下方提示文字：
    > 暂无文献。点击「检索」从OpenAlex/Crossref/arXiv 检索，或「导入」BibTeX/RIS。
4.  **底部版本说明**
    页脚浅灰色小字标注：
    `Selenyx R109 · 2026-08-07 · 自动检测新版本，若未更新请按Ctrl+Shift+R 强制刷新`
