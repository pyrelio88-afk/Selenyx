这是一款效率类时间管理工具的界面截图，整体为米白底色搭配细黑圆角边框的简约设计，共分为两个功能模块：
---
### 1. 倒数日添加区
顶部是带有灰色虚线内边框的输入栏，浅灰色占位提示文字为：
`+ 添加你的第一个倒数日（如：科研基金申报截止）`
---
### 2. 番茄钟功能区
下方是独立的番茄钟功能卡片：
- 卡片头部：左侧搭配网格样式的功能图标，标注黑色粗体标题「番茄钟」，右侧浅灰色文字标注当前使用进度：`已完成 0 轮专注`
- 计时选项按钮排布如下：
| 按钮状态 | 按钮内容 |
| ---- | ---- |
| 未选中（白底黑字） | 深度专注 50m |
| 已选中（绿底白字） | 专注 25m |
| 未选中（白底黑字） | 长休息 15m |
| 未选中（白底黑字） | 短休息 5m |
| 未选中（白底黑字） | + 自定义 |
- 卡片底部露出了对应选中模式的绿色倒计时数字开头：`25:00`
