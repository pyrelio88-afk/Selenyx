# Selenyx 需求账本（用户口径，2026-08-12）

> 来源：本轮交接任务书 + 对话纠正。空壳 UI = Critical。不推翻技术栈。

## 产品红线

- 别人交报告，Selenyx 交证据链：agent 跑腿，人落锤。
- 证据门不可绕过：写卡只能 pending；`[^e:id]` 必须后端校验（无项目 run 也要打回）。
- 本地优先：数据/密钥/记忆不出本机。唯一出口是用户自己的 LLM 网关与学术连接器。
- 监听地址跟**当前使用者这台机器**走（本机回环），禁止把开发机/某台局域网 IP 写死进产品文案或配置。
- 空壳按钮 = Critical。不换栈、不引重型 agent 框架。
