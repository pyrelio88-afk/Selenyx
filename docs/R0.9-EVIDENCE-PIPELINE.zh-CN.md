# Selenyx R0.9 — 证据门科研工作台

## 流水线依据（不是拍脑袋）

侧栏阶段对齐两套可复核来源：

1. **Claude Scholar** Core Workflow  
   `question → evidence → experiment → analysis → claim → writing`  
   文献：search / import / read notes → 证据闸门 → 写作

2. **nature-skills（Yuan1z0825）18+ skills** 映射到阶段能力  
   检索 · 下载/获取全文 · 阅读 · 论文卡片 · 引文核验 · 写作/润色 · 审稿 · 实验日志 · 图表 · 统计

3. **Selenyx 内置 RESEARCH_STAGES**  
   `question → discover → screen → read → evidence → synthesize → write → review`

## 侧栏（对用户真正有用的顺序）

| 区 | 视图 | 作用 |
|---|---|---|
| 立题 | 研究问题 | 先确认边界，生成证据门路径 |
| 文献 | 文献检索 | 真 API / 站点跳转分开 |
| 文献 | 获取全文 | 内置浏览器 + 登录墙外开 |
| 文献 | 本地文献库 | 收藏 + **导入 PDF** |
| 文献 | 阅读 · PDF | pdf.js 翻页 + 选区批注/证据 |
| 证据 | 证据链 | 支持/反驳/限定 + 审阅闸门 |
| 证据 | 综合路径 | Nature 能力内化，非技能墙 |
| 产物 | 写作 | 仅从已审阅证据生成提纲 |
| 产物 | 图表规划 | 骨架；诚实声明需 Python/R |
| 产物 | 实验日志 | nature-experiment-log L1 |
| 协作 | 科研对话 | BYOK L2 / 离线诚实降级 |

## PDF 闭环（本轮核心）

```
检索命中 → 获取全文（浏览器）→ 用户手动下载 PDF
→ 导入 PDF（本地库 / 阅读器 / 浏览器工具栏）
→ pdf.js 阅读 → 高亮/批注/加入证据 → 写作提纲
```

- PDF 存 `%AppData%/selenyx-desktop/papers/`
- 元数据进 `workspace.json` 的 `localPdf`
- 不假装能自动冲破知网登录墙

## 启动（Windows Smart App Control）

未签名 `Selenyx.exe` 可能被系统拦截。请用：

- 桌面文件夹 `Selenyx/` 内的 `启动 Selenyx.bat`
- 或 `desktop/start-selenyx.bat`（Electron 开发通道）
