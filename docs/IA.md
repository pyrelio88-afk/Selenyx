# 信息架构（放哪）

科研闭环：对话干活 → 项目管进度 → 工具做事 → 自动化定节奏 → 知识库存证据 → 专家/技能是能力。

| 功能 | 放哪 | 不放哪 | 原因 |
|---|---|---|---|
| 新对话 / agent run | 新对话 | 独立「助理」页 | 提交即进这场对话 |
| 项目、流水线、删除课题 | 项目 | 侧栏 | 生命周期只在项目页 |
| 截稿/答辩/伦理倒数日 | **项目卡** | 工具/更多 | 是课题进度 |
| 表格、图片文件、统计、DOI/引用 | **工具** | 知识库 | 你点名归到项目下面的工具 |
| 文献、证据卡、笔记、临床手册 | 知识库 | 工具 | 证据资产 |
| 专家人格、技能、MCP、Zotero | 专家·技能·连接器（侧栏最下） | 知识库 tab | 能力入口 |
| 每日监测、定时综述 | 自动化 | 项目卡片 | 节奏触发 |

侧栏顺序：新对话 → 项目 → 工具 → 自动化 → 知识库 → 专家·技能·连接器
