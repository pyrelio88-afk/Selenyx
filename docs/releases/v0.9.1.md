# Selenyx v0.9.1 — Research Workbench

Selenyx v0.9.1 promotes the validated local-first research workflow to a stable release.

## Highlights

- Research-question-first project creation with an offline evidence plan.
- China-first source navigation plus real OpenAlex, PubMed, and Crossref API search by default.
- Strict full-title matching: fabricated titles stay at zero instead of becoming loose keyword results.
- Cross-source deduplication that preserves the first authoritative record.
- Built-in research browser with explicit blocked, timeout, login-wall, and system-browser fallbacks.
- Local PDF import and first-screen reading with page jump, zoom, fit-width, rotation, and document search.
- Anchored highlights, annotations, evidence capture, and restart recovery.
- Nature Skills adapted into the research workflow rather than presented as decorative skill cards.
- New paper-white, warm-gray, and cinnabar desktop identity with Windows taskbar and installer icons.

## Verification
